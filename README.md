# Formula Proibida

CRIAR FUNIL DE VENDAS — FÓRMULA PROIBIDA

Quero que você construa uma página de vendas completa para o produto Fórmula Proibida, seguindo FIELMENTE as imagens de referência que estou anexando.

As imagens anexadas são a principal fonte de verdade para o DESIGN.

Não quero um template genérico do Lovable. Quero que você analise as referências e reproduza a mesma lógica visual, composição, hierarquia, espaçamento, proporções, tipografia, cores, cards, botões, imagens e comportamento responsivo, adaptando o conteúdo ao produto abaixo.

1. PRIORIDADE DO PROJETO

Priorize nesta ordem:

IMAGENS DE REFERÊNCIA → ESTRUTURA → HIERARQUIA VISUAL → ESPAÇAMENTO → TIPOGRAFIA → CORES → RESPONSIVIDADE → FUNCIONALIDADE

Não invente elementos visuais desnecessários.

Se alguma informação não estiver disponível, use um placeholder claramente identificável em vez de inventar dados.

Use os assets/imagens que eu fornecer. Não substitua imagens fornecidas por imagens genéricas ou stock.

2. PRODUTO

Nome: Fórmula Proibida

Preço: 5.900 Kz

Produto digital em PDF.

Público: adultos em Angola.

A comunicação deve ser persuasiva, mas responsável.

Não fazer promessas médicas absolutas nem garantir resultados.

Não inventar:

depoimentos;

clientes;

especialistas;

certificados;

resultados;

números de vendas;

notificações de compra;

escassez;

garantias inexistentes;

contadores falsos.

mobile.

Não permitir scroll horizontal.

6. CTA COM DELAY DE 7 MINUTOS E 20 SEGUNDOS

O CTA principal associado à VSL deve ficar completamente oculto inicialmente.

Após exatamente:

7 minutos e 20 segundos = 440 segundos

o botão deve aparecer automaticamente.

Antes dos 440 segundos:

não mostrar o botão;

não mostrar botão desabilitado;

não mostrar uma versão alternativa;

não criar espaço visual desnecessário.

Depois dos 440 segundos:

revelar o botão com uma animação suave;

botão grande;

fundo vermelho;

texto branco;

bordas arredondadas;

efeito de pulsação contínua;

alto contraste;

excelente visibilidade no mobile.

Texto do CTA:

QUERO GARANTIR MEU ACESSO AGORA

Ao clicar:

/checkout

O botão permanece visível depois de aparecer.

IMPORTANTE:

O delay é apenas para controlar a apresentação do CTA.

Não criar:

contador regressivo falso;

falsa escassez;

falsas notificações de compra;

falsas vagas limitadas;

qualquer outro mecanismo enganoso.
